# Launch requirements

Prepared November 14, 2026 for **CartScope Launch Candidate 0.1.2** (`PREVIEW 0.1.2`; manifest name **CartScope — Shopping desk**). This matrix maps the six launch deliverables to their locations and evidence gates. **Prepared** means the local material exists. It does not mean it has been published, sent, submitted to Google, or approved.

| # | Required deliverable | Location | Current status / remaining evidence |
| --- | --- | --- | --- |
| 1 | Link to the extension published on the Chrome Web Store | [Store listing kit](STORE_LISTING.md), [permissions/disclosures](PERMISSIONS_AND_DISCLOSURES.md), [privacy policy](PRIVACY_POLICY.md), [reviewer instructions](REVIEWER_INSTRUCTIONS.md), [assets](assets/README.md), and [publication metadata](launch-metadata.json) | **Pending externally.** No verified Store URL, publisher access, submission confirmation or approval is recorded. `chrome_web_store_url` remains null. Submit under REL-12; verify the actual public listing and installation under REL-13. A kit or GitHub release does not satisfy this item. |
| 2 | Version-controlled GitHub repository with release notes and usage instructions | [qarteu/cartscope](https://github.com/qarteu/cartscope), [README](../../README.md), [release notes](../../CHANGELOG.md), [release index](https://github.com/qarteu/cartscope/releases) | **Historical repository available; launch revision prepared locally.** Alpha [0.1.0](https://github.com/qarteu/cartscope/releases/tag/v0.1.0) and [0.1.1](https://github.com/qarteu/cartscope/releases/tag/v0.1.1) remain the published history.
