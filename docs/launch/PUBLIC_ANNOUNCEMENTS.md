## Alternate GitHub-preview announcement — draft

### Project announcement

We've built CartScope, a Chrome shopping desk for the products you're deciding between.

Save a product after checking its details, add offers for the same model and variant, and compare the costs you've recorded. Keep quantities, an item budget, notes, and manual order details together in one panel. Your records are stored locally; there's no CartScope account or analytics backend.

This is an early preview. It doesn't search every store or watch prices while you're away. Price/restock alerts need another capture or offer update, orders are manual, and final costs and availability stay with the retailer. The sample workspace is labeled so you can explore without buying anything.

Try the [browser demo](https://qarteu.github.io/cartscope/) or [download the Chrome preview and release notes](https://github.com/qarteu/cartscope/releases). For local installation, unzip the release, open `chrome://extensions`, enable Developer mode, and load the folder containing `manifest.json`.

We'd like honest feedback: which task got stuck, how clear were the costs, and what should we improve first? [Send task outcomes, ratings, and written feedback](https://github.com/qarteu/cartscope/issues/new?template=alpha-feedback.yml). Public issues should not include personal order or payment information.

Built by Kartik Malunjkar, Jake Clevenger, and Eashan. Source: https://github.com/qarteu/cartscope
